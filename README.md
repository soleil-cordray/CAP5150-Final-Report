# Malware Behavior Comparison: Remote Access Trojan, Fileless, and Living-off-the-Land

Completed as a semester-long project for CAP5150: Foundations of Computer Security & Privacy, taught by David Mohaisen.

The Living of the Land (LOTL) and fileless loader artifacts have been commented out and converted to pseudocode in order to prevent malware reproducability. These artifacts were analyzed without using Ghidra.

The third artifact (analyzed using Ghidra), RemcosRAT, can be found at [MalwareBazaar](https://bazaar.abuse.ch/sample/32aa0546c952a980435c113eeb04b6f9a82bf2b260e0b7b261010eaa585d55f1/).
